# はじめに
- 本リポジトリではプログラム学習において、一般的なプログラミングの(言語依存しない)知識を学んだのち、
    フロント: HTML / CSS / Bulma
    バックエンド: JavaScript(Node.js/Express)
    DB: MongoDB → MySQLへ変更
  を使用して、作成したアプリケーションです。

- ご利用にいただくことでのトラブルは一切責任を負いかねます。

# コンセプト
- 母が毎日、冷蔵庫の食材の残り物の管理、加えて、そこからできる料理を考えるルーティンを素早く完了するために毎日の残りの食材管理と
- その食材からできる人気料理を検索できるアプリケーションを要望をもとに、要件定義・設計・実装をしました。
- よくあるアプリかもしれませんが、暖かい目で見ていただければ、幸いです。

# アプリ概要
- 現状、新規登録はユーザー名、パスワード、メールアドレスで作成
  →今後、FacebookなどのSNSでのログインを実装予定
- ログイン後、新規登録後には初期で４つの食材がすでに登録されています。
- 「編集」ボタンを押すことで、入力→「Enter」で食材が(一時的に)記録されて、更新することで残り食材をアップデートできます。
- Home画面において、食材をクリックすることで自動的に、検索フォームに加わり、「検索」することで食材から料理を検索してくれます
  →今後、現在「楽天レシピAPI」を使用しています。そのカテゴリーにある食材名である必要があるため、文字の違いで検索に上がらないので、変更を予定。
